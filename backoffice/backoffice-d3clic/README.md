# Back-office D3clic — production

`index.html` est la source versionnée de l’interface de production à installer
sur Infomaniak dans `/backoffice-d3clic/index.html`.

Cette interface pointe vers le projet Supabase `d3clic-chat`
(`ittlvqwgdsgzbgnjyexj`).

Elle gère les permissions par module du back-office :
- Collaborateurs
- Onboarding
- Canaux
- Documentation IA
- Règles IA

URL de production et de redirection Supabase Auth :

`https://d3clic-suite.ch/backoffice-d3clic/index.html`

La page staging reste séparée dans `backoffice/rag-staging/`.
